# Image Watermarking Desktop App
A simple image watermarking tool built using Python and the Tkinter GUI library.

1. Clone the repository:

2. Install the required packages:

3. Run the application:

## Usage
1. Launch the application and upload an image.
2. Type the preferred watermark text into the input field.
3. Customize the watermark attributes—size, transperancy and position.
4. Press the "Apply Watermark" button to apply the watermark to the image.
5. Hit the "Save" button to store the final watermarked image on your local device.
